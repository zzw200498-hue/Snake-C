# 贪吃蛇 2.0（控制台优化版）

在 1.0 的基础上修掉了刷新 bug，改成**局部刷新**，能稳定流畅地玩了。

## 编译运行

用 Visual Studio 打开 `贪吃蛇.sln` 直接编译（控制台项目）。

程序启动时会自己把窗口调成 `80 x 50` 字符，保证 60x40 的地图放得下。

## 源码文件

| 文件 | 说明 |
|------|------|
| `Snake.h` | 地图尺寸、结构体定义、函数声明 |
| `Snake.c` | 全部逻辑 |

## 相比 1.0 改了什么

### 1. 修掉尾巴残留 `#` 的 bug

1.0 的问题是**每帧把整条蛇重画一遍**，然后再去擦尾巴那一格。
重画和擦除互相干扰，食物刷在蛇尾位置时就会露出脏东西。

2.0 改成**只刷新真正变化的那几个格子**：

```c
/* 1. 擦掉旧尾巴 */
Gotoxy(tailX + 1, tailY + 1); putchar(' ');
/* 2. 画新蛇头 */
Gotoxy(Snake.body[0].X + 1, Snake.body[0].Y + 1); putchar('@');
/* 3. 原来的蛇头位置变成身体 */
Gotoxy(Snake.body[1].X + 1, Snake.body[1].Y + 1); putchar('*');
/* 4. 在新位置画食物 */
Gotoxy(Food.X + 1, Food.Y + 1); putchar('#');
```

每帧只动 4 个格子，不再全屏重画，也就没有刷新冲突和闪烁了。

### 2. 地图和边框

- 画了完整的上下左右边框，右上角不再缺一块
- 食物生成范围改成 `2 ~ W-2` / `2 ~ H-2`，不会贴着边框生成
- 开局长度从 2 加到 3，看起来更像条蛇

### 3. 帧节奏

循环开头先 `Sleep(S)` 再处理按键，节奏更稳（1.0 是每帧全量重画之后才 Sleep）。

### 4. 更清楚的提示

撞墙和撞自己分别给出不同的结束提示。

## 玩法

- `w` `a` `s` `d` 控制方向
- 吃到 `#` 加 10 分，蛇变长，速度变快
- 撞墙或撞到自己就结束

## 这一版仍然没解决的问题

画面还是**字符**：蛇头 `@`、蛇身 `*`、食物 `#`，背景是黑窗口。
想要真正的画面，看[第三版](../贪吃蛇3/)。
