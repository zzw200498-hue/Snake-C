# 贪吃蛇 1.0（原始版）

最早写的控制台贪吃蛇。用 `@` 表示蛇头、`*` 表示蛇身、`#` 表示食物。

## 编译运行

用 Visual Studio 打开 `贪吃蛇.sln`，或者把 `Snake.c` / `Snake.h` 加进一个
控制台项目直接编译。

## 源码文件

| 文件 | 说明 |
|------|------|
| `Snake.h` | 地图尺寸、结构体定义、函数声明 |
| `Snake.c` | 全部逻辑 |

## 玩法

- `w` `a` `s` `d` 控制方向
- 吃到 `#` 加 5 分，蛇变长，每满 30 分加速一次
- 撞墙或撞到自己就结束

## 这一版的问题

1. **尾巴偶尔残留 `#`**：`Init_UI()` 里先画蛇，再把尾巴那一格擦成空格，
   最后画食物。如果食物正好生成在蛇尾刚离开的那一格上，
   擦除和绘制就会打架，屏幕上偶尔闪出不该有的 `#`。
   根因是**每一帧都全量重画一遍蛇身**，而不是只刷新变化的那几格。

2. **闪烁**：同样是每帧重画整条蛇造成的。

3. 食物是 `#`、蛇头是 `@`、蛇身是 `*` —— 全都是字符，谈不上画面。

这些问题在[第二版](../贪吃蛇2/)里修掉了，在[第三版](../贪吃蛇3/)里被彻底重写。
