# 贪吃蛇 —— 三个版本

用 C 语言写的贪吃蛇，从最原始的控制台字符版一路做到窗口图形版。

| 目录 | 版本 | 说明 |
|------|------|------|
| [`贪吃蛇damo/`](贪吃蛇damo/) | 1.0 | 最早的原始版。控制台 + `@` `*` 字符，可以玩，但有个刷新小 bug |
| [`贪吃蛇2/`](贪吃蛇2/) | 2.0 | 修掉 bug 的版本。控制台 + 局部刷新，稳定流畅 |
| [`贪吃蛇3/`](贪吃蛇3/) | 3.0 | **全新重写**。真正的图形窗口、平滑移动、漂亮的蛇和苹果、完整 UI、最高分记录 |

> **2026-10 更新（3.1）**：修好了"一顿一顿"的卡顿（计时器精度 + 主循环重写，
> 实测整帧 3.7ms、帧间隔抖动 0.35ms）；棋盘从 26×19 扩到 **34×24**；
> 蛇重做了 —— 8 段渐变色带、顺身体方向的菱形鳞片、整条蛇会"游"起来的波浪动画、
> 更精致的蛇头。详情见 [贪吃蛇3/README.md](贪吃蛇3/README.md)。

## 贪吃蛇 3.0 —— 直接玩

不用编译，双击就能玩：

```
贪吃蛇3\build\Snake3.exe
```

Windows 10 / 11 直接运行，不需要装任何运行库，也不用装 Visual Studio。
想发给朋友的话，把 `Snake3.exe` 这一个文件发过去就行。

### 操作

| 按键 | 作用 |
|------|------|
| `↑` `↓` `←` `→` 或 `W` `A` `S` `D` | 控制方向 |
| `空格` / `P` / `Esc` | 暂停 / 继续 |
| `空格` / `R` | 结束后再来一局 |
| `Esc` / `Q` | 回到主菜单 |
| 鼠标 | 菜单和结算界面上的按钮可以直接点 |

最高分会自动保存，下次打开还在。

## 3.0 相比前两版做了什么

### 1. 流畅 —— 蛇是"滑"着走的，不是一格一格跳

前两版每次移动都是瞬间跳一格。3.0 把**逻辑**和**画面**分开了：

- 逻辑上蛇还是按格走（所以判定精确、不会穿模）
- 画面上每个身体点都用 `lerp` 平滑追赶目标格，
  并且用**帧率无关**的指数插值 `1 - exp(-dt/τ)`，
  这样不管你是 60Hz 还是 144Hz 显示器，手感完全一样

拐弯的时候蛇是会画弧线的，不是在直角处生硬地折一下。

### 2. 建模 —— 蛇身是一整条，不是一串珠子

这是这一版花功夫最多的地方。**早期实现在这里翻过车**：
如果每一节各画一个圆，放大看就是一串断开的珠子，接缝处还会露背景。
现在的画法是分 5 遍叠出来的：

1. **胶囊连接**：用 `eng_capsule`（两端带半圆的粗线）把相邻两点连起来，
   铺出一条**连续**的身体轮廓 —— 这是关键，接缝处完全融合，
   像素级检查确认整条蛇是一个连通区域，不是十几个分离的圆
2. **描边**：在轮廓下面垫一层大一圈的深色，形成柔和的边
3. **体积感**：沿身体连续画一条偏移的背部高光 + 一条偏移的腹部亮色，
   看起来就成了一根有明暗的"管子"，而不是一块块平涂
4. **鳞纹**：每隔一节点一片小菱形，带轻微的呼吸动画
5. **头部**：圆润的脑袋、两只白眼珠（瞳孔偏向前进方向）、
   眼里的反光点、会快速伸缩的**分叉舌头**、两个鼻孔

尾巴用锥形收窄，从前段几乎保持粗细、到最后 40% 快速收成尖端，
比均匀变细更像真蛇。

### 3. 食物 —— 真正的苹果贴图

不是画个红圆点，是完整的一个苹果：

- 果实本体：深色描边 + 主体 + 左下暗部 + 右上受光面 + 高光点
- 顶部有个**凹口**（苹果特有的形状）
- 棕色**果柄**
- 绿色**叶子**，带中脉高光，一眼就能看出是叶子
- 落地阴影
- 还会轻微地**呼吸和摇摆**，静止的食物也有生气

> 这里也修过一个 bug：苹果靠近棋盘最上面一行时，
> 叶子和果柄会伸出格子上方、画到顶部信息栏上去。
> 现在给棋盘加了裁剪区（`eng_clip`），并把球体在格子里稍微下移，
> 让叶子和果柄有地方放。

### 4. UI —— 全套真正的界面

- **主菜单**：大标题、最高分卡片、三个可点/可选的按钮（开始 / 难度 / 退出）、
  背景里有一条缓慢游动的装饰蛇
- **游戏中 HUD**：左侧大号得分（吃到苹果会跳色）、中间最高分、右侧长度和苹果数
- **暂停**：半透明遮罩 + 卡片
- **结算**：本局得分、吃到几个苹果、历史最高分；
  破纪录时显示闪烁的「★ 新纪录！★」
- **难度**：悠闲 / 标准 / 疾速三档，影响初始速度
- 全部用微软雅黑绘制中文，按屏幕 DPI 自动缩放（高分屏不糊）
- 双缓冲渲染，**完全无闪烁**

### 5. 最高分记录

存在 `%APPDATA%\Snake3\save.dat`（二进制，只存最高分和总局数）。
放在 APPDATA 而不是 exe 旁边，是因为如果 exe 放在 `C:\Program Files`
之类的目录下，旁边是写不进去的。写入前会做范围校验，防止存档损坏导致显示怪数字。

### 6. 其他细节

- 撞死时屏幕**抖动**一下
- 吃到苹果时蛇头有一圈金色光环扩散
- 速度随分数渐快（每吃一个苹果快一点，有下限，不会快到没法玩）
- 摸到窗口失焦时自动松开所有按键，不会出现"回来以后蛇一直自己跑"
- 防止快速连按两次方向导致掉头自杀（方向缓冲会先判断合法性）
- **同时提供 `main` 和 `WinMain` 两个入口**，用 `/SUBSYSTEM:WINDOWS`
  （推荐，运行时没有黑窗口）或者控制台子系统、或者 gcc 直接编译，
  都不会链接失败

## 自己编译

需要 Visual Studio 2022（免费的 Community 版就行），安装时勾选
**「使用 C++ 的桌面开发」**。

然后双击：

```
贪吃蛇3\build.bat
```

脚本会自己去找 VS 的编译环境（支持 Community / Professional / Enterprise /
BuildTools / VS2019，也会用 `vswhere` 兜底），你不用改任何路径。
编译完会生成 `build\Snake3.exe`，并问你要不要马上打开。

命令行等价写法：

```bat
cl /nologo /utf-8 /W3 /O2 /MT /DNDEBUG ^
   /Fe:build\Snake3.exe /Fo:build\ ^
   src\engine.c src\art.c src\game.c ^
   /link /SUBSYSTEM:WINDOWS user32.lib gdi32.lib shell32.lib winmm.lib
```

- `/utf-8`：源文件带中文注释，必须加
- `/MT`：静态链接 C 运行库，生成的 exe 才能单独发给别人

### 用 MinGW / Dev-C++ 编译

源码是标准 C，没有用 MSVC 独有的东西。注意用**控制台子系统**链接
（因为 MinGW 走 `main` 入口）：

```bash
gcc -O2 -municode -o Snake3.exe src/engine.c src/art.c src/game.c \
    -luser32 -lgdi32 -lshell32 -lwinmm -mwindows
```

## 自测

3.0 带一个自测模式，不需要人操作，会自动玩一会儿并截图：

```bat
build\Snake3.exe --selftest 输出文件前缀
```

它会：
1. 开一局，用简单 AI 自动去吃苹果，跑 300 帧
2. 校验得分和吃到苹果数对不对得上
3. 分别渲染并保存主菜单、结算界面、以及"苹果顶在最上面一行"的画面
4. 输出一个 `.log` 文件

最后一个场景是专门用来抓裁剪 bug 的 —— 苹果和蛇都放在第 0 行，
它们向上突出的部分必须被挡在信息栏下面。

## 已知限制

- 只支持 Windows（用的是 GDI 和 Win32 API）
- 苹果和蛇是用矢量代码画的，不是位图文件。
  好处是整个项目拷到哪都能编译、方便改配色，
  代价是细节不如手绘贴图丰富
- 存档只有"最高分"一项，没有做多档排行榜
